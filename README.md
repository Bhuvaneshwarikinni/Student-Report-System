# Student Tracker
# Student Management / Student Report System

A Python-based student management system that stores student information in a SQLite database and generates student reports.

## 📌 Project Overview

This project is designed to manage student data efficiently using Python and SQLite. It allows student information to be stored in a database and used to generate student reports.

## 🚀 Features

* Add and manage student information
* Store student data using SQLite database
* Retrieve student records
* Generate student reports
* Store generated reports in a text file
* Simple and easy-to-use Python implementation

## 🛠️ Technologies Used

* **Python**
* **SQLite**
* **Database Management**
* **Text File Handling**

## 📂 Project Structure

```text
Student-Management/
│
├── student_tra.py        # Main Python program
├── students.db           # SQLite database containing student data
├── student_report.txt    # Generated student report
├── package-lock.json     # Project dependency lock file
└── README.md             # Project documentation
```

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
```

### 2. Open the project folder

```bash
cd <project-folder>
```

### 3. Run the Python program

```bash
python student_tra.py
```

If your system uses `python3`:

```bash
python3 student_tra.py
```

## 🗄️ Database

The project uses **SQLite** to store student information.

The database file is:

```text
students.db
```

The Python program interacts with this database to store and retrieve student records.

## 📄 Student Report

The generated student information/report is stored in:

```text
student_report.txt
```
